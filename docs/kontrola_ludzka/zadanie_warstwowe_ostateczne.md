**Odpowiedź:**

In PHP, you can use the `sprintf` function to format a float number with exactly two decimal places. The `sprintf` function allows you to specify a format string that defines how the number should be formatted.

Here’s how you can use `sprintf` to print a float number with **two decimal places**:

```php
$number = 123.456;
$formatted = sprintf("%.2f", $number);
echo $formatted; // Output: 123.46
```

### Explanation:
- `%.2f` is the format specification:
  - `%` starts the format specifier.
  - `.` indicates that it's a floating-point number.
  - `2` specifies that two decimal places should be displayed.
  - `f` stands for floating-point number.

### Example with different numbers:
```php
echo sprintf("%.2f", 10.5);    // Output: 10.50
echo sprintf("%.2f", 2.345);  // Output: 2.35
echo sprintf("%.2f", 0.9);    // Output: 0.90
```

### Notes:
- The number is **rounded** to two decimal places.
- If you want to **truncate** instead of round, you would need to use additional logic or functions like `floor` or `number_format`.

**Odpowiedź:**

The sentence *"He looked at the door, chewing on a stick of gum"* is a **compound sentence** with two actions. It consists of a **main clause** and a **dependent clause**, connected by a comma. Here's how it can be diagrammed:

---

### **Main Clause:**
**He looked at the door**

- **He** – Subject  
- **looked** – Verb (past tense)  
- **at the door** – Prepositional phrase (object of the verb "looked")

---

### **Dependent Clause (Participle Phrase):**
**chewing on a stick of gum**

- **chewing** – Present participle (acting as an adjective or adverb)  
- **on a stick of gum** – Prepositional phrase (complement of the participle)

---

### **Diagram:**

```
           He looked at the door,
                   |
                   ———————
                  |       |
          chewing on a stick of gum
```

---

### **Alternative Diagram (more structured):**

```
           He looked at the door,
                   |
                   ———————
                  |       |
          chewing on a stick of gum
```

---

### **Explanation:**

- **"He looked at the door"** is the main clause.
- **"chewing on a stick of gum"** is a **present participle phrase** that modifies the main clause, showing what he was doing while looking at the door.
- The comma separates the main clause from the participle phrase, which is a **non-restrictive** or **non-essential** addition.

This structure is common in **compound sentences** where one action is the main focus and the other is a **simultaneous or ongoing action**.

$$
\text{总费用} = \text{货物体积（cbm）} \times 64.52
$$

例如：
