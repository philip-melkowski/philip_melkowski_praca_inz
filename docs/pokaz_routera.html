Pokaz routera w DeepFellow

Kliknij „Wyślij” przy zapytaniu. Strona pokazuje, który model odpowiedział, która warstwa zdecydowała, wyniki kNN i modelu decyzyjnego, czas decyzji, czas całego zapytania i odpowiedź.

Uruchomienie DF i instalacja (przed pokazem)

Pierwszy terminal: start DF na gałęzi pokazowej. Drugi: instalacja Ollamy i routera z warstwą 3 (Clef). Potrzebny VPN do df.test i działająca Ollama z qwen3:8b i nomic-embed-text.

cd ~/inz/deepfellow-infra
git switch demo/seminarium-dftest
mkdir -p /tmp/df-pokaz
eval "$(grep '^export API_KEY=' ~/.zshrc)"
DF_TEST_API_KEY="$API_KEY" DF_STORAGE_DIR=/tmp/df-pokaz \
DF_INFRA_ADMIN_API_KEY=pokaz-admin DF_INFRA_API_KEY=pokaz-key \
uv run uvicorn server.main:app --host localhost --port 8087 --log-level info
B=http://localhost:8087; A="Authorization: Bearer pokaz-admin"; R=$HOME/inz/philip_melkowski_praca_inz
curl -s -X POST $B/admin/services/ollama-external -H "$A" -H "Content-Type: application/json" \
  -d '{"spec":{"url":"http://localhost:11434"}}'; echo
curl -s -X POST $B/admin/services/router -H "$A" -H "Content-Type: application/json" -d "{\"spec\":{
  \"small_model\":\"qwen3:8b\",\"large_model\":\"Qwen/Qwen3.8-27B-FP8\",
  \"index_path\":\"$R/data/router/router_index_train_cal.npz\",\"embedding_model\":\"nomic-embed-text\",
  \"k\":\"20\",\"threshold\":\"0.3\",\"heuristics_path\":\"$R/data/router_l1.json\",\"heuristic_threshold\":\"2\",
  \"decider_path\":\"$R/data/router/router_l3_clef_v1.json\"}}"; echo
curl -s -X POST "$B/admin/services/router/models/_?model_id=router" -H "$A" -H "Content-Type: application/json" \
  -d '{"spec":{}}'; echo

Przed wejściem na salę wyślij raz zapytania 2 i 4: pierwsze wywołanie ładuje modele do pamięci.
